# Codex Toolbox 1.4.0 / Build 53 修订

2026-10-04 用户确认实施。本文件替代 Build 52 计划中账户分析页面、套餐历史、可增删排序菜单栏和共用外观的描述。

- 雷达日期栏恢复 1.3.1；Token 模块更名“用量分析”，保留两张原有卡片及交互，删除来源切换和账户分析。
- 本机 Token/等值成本保留所有本机历史。原生累计账户数据不替换本机日统计；只接受账户、设备、时间、指标、完整性均一致的来源，当前报表不满足，停止其请求。
- 明确区分 ChatGPT/API/未登录/未知身份；额度缓存、观测和请求代次隔离。历史归属未知时不回填，不以创建者推断付款账户。
- 账户模块更名“账户额度&重置卡”，同步图标和说明，统一中文北京时间，移除套餐历史。看板保留完整额度显示。
- 固定三个自由槽位，默认综合/今日 Token/账户额度，仅首项开启；至少保留一项。旧设置迁移一次，Build 52 ID/启停/内容保留。
- 顶部常驻三项预览，禁用灰显；榜单/Token/额度独立样式；Token 完整或 K/M/B；额度条/圆圈/关闭互斥，百分比/图标/彩色独立。
- NSStatusItem 使用稳定 ID/autosaveName 与 isVisible，位置交给 macOS，禁止主动删除保存位置。
- 生成 1.4.0 Build 53 签名公证 Universal 2 PKG，交用户手动覆盖安装；不公开发布。用户后续明确要求测试由其手动完成，收到指示后停止测试，仅完成已经开始的 Apple 公证与交付。

验证结果单独记录在 docs/verification/v1.4.0-build53.md；自动化、界面、覆盖安装及公开发布是不同验收项。
