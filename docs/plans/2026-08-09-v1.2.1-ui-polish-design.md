# Codex Toolbox v1.2.1 界面整理设计

## 目标

本次更新只调整展示和设置信息架构，不改变榜单、Token 账本、重置卡或更新流程的数据行为。

- Token 任务卡的总数独占一行；无论位数多少都保持单行，并在必要时平滑缩小字号。
- 四宫格榜单继续显示完整模型名，先使用系统字距收紧和有限字号缩放，空间仍不足时才从中间省略。
- “智商显示”按菜单栏、榜单、变化趋势、数据刷新、综合排名权重分组，减少单一区块中的连续控件。
- 通用、Token 和重置卡页面只保留可操作设置；数据访问与隐私说明集中到“关于”的二级页面。

## 实现与验证

Token 总数从与右侧状态控件竞争宽度的嵌套列中移出，顶部只保留标题和状态，数字获得整张卡片的可用宽度。榜单不引入硬编码模型简称；完整标签仍是唯一内容源，SwiftUI 仅在布局不足时缩放或截断。

设置首页保留现有五个标签页和所有偏好键，只拆分视觉分组，并新增“关于 → 数据与隐私详情”导航。自动测试、CoreVerification、完整 Xcode 测试、Universal 2、Developer ID 签名、公证、staple 与 Gatekeeper 均作为手动测试安装包的交付门禁；真实界面验收由用户安装后完成，验收前不发布 GitHub Release。
