# 模型趋势交互设计

## 目标

变化趋势应像其他看板内容一样即时、可中断地展开和折叠，同时让用户直接理解每种曲线颜色对应哪个模型。默认仍展示当前指标 Top 3；用户可以保留 1–5 条曲线，并随时恢复动态 Top 3。

## 结构与数据流

趋势入口常驻时先在后台完成当前指标与时间范围的日期解析、按日聚合、可绘制模型分组和默认 Top 3 计算。该结果不包含用户当前选择，因此换模型、增删曲线只从已准备的数据中过滤，不再重新解析完整历史。每个指标保留独立的有序模型 ID 数组；数组位置稳定映射蓝、绿、橙、紫、粉五个系统语义色，并继续使用统一的 `ModelCatalog` 家族子菜单。

展开内容采用与其他看板相同的临界阻尼弹簧和顶部锚定淡入缩放，Reduced Motion 下退化为短交叉淡化。顶部只保留指标分段控件和曲线数量；图表关闭自动图例，底部以紧凑三列颜色槽展示“颜色、模型菜单、删除”，默认三条曲线保持同一行，再提供按家族分类的添加菜单与恢复默认按钮。

## 会话行为与验证

“固定展开”默认关闭，并在“显示模型趋势入口”关闭时禁用。开启后，首次创建看板以及每次 `NSPopover` 即将显示时把趋势设为展开；用户仍能在当次会话手动折叠，弹窗关闭后重置，下次打开再按设置恢复。

验证覆盖默认值和持久化、五条上限、去重、默认 Top 3、颜色槽顺序、恢复默认，以及 SwiftPM/Xcode 全量测试。性能验证使用真实缓存和进程采样，确认历史准备不占用主线程、曲线选择不触发重新解析；最终以用户手动安装包的实际动效与排版验收为准。
