## 性能对照

最终运行使用相同匿名 fixture 和冻结的新旧源码，开启优化编译。1 倍输入为 150 天 / 65,251 观测 / 34,695 原生快照；5 倍为 750 天 / 326,255 观测 / 173,475 快照。历史额度和原生额度逐字段相同，百分比误差不超过 `1e-6`，精度标记、时间戳和缺失状态一致。完整数值输出留在受限 private 目录，不进入仓库。

| 计算 | 1.4.1 基线 | 1.4.2 候选 |
|---|---:|---:|
| 历史额度，1 倍 | 4.583821 s | 0.214909 s |
| 历史额度，5 倍 | 111.571729 s | 1.237536 s |
| 原生额度，1 倍 | 0.139359 s | 0.143035 s |
| 原生额度，5 倍 | 0.922435 s | 0.743758 s |

原生额度 1 倍时间略有波动，没有将它计作性能提升。

| 稳态追加场景 | 基线写入 | 候选写入 | 基线 CPU / 候选 CPU |
|---|---:|---:|---:|
| 账户采样，1 倍 | 58,716,160 B | 163,840 B | 1.008487 / 0.001033 s |
| 账户采样，5 倍 | 294,625,280 B | 102,400 B | 4.915479 / 0.000744 s |
| 原生快照，1 倍 | 24,752,128 B | 102,400 B | 0.477492 / 0.000636 s |
| 原生快照，5 倍 | 124,579,840 B | 102,400 B | 2.390873 / 0.000471 s |
| 单个长会话，65,250 记录后追加 1 条 | 18,657,280 B | 237,568 B | 0.562470 / 0.171619 s |
| 单个长会话，326,250 记录后追加 1 条 | 93,548,544 B | 282,624 B | 2.847839 / 0.859642 s |

上述稳态追加写入减少 98.73%–99.97%，组件 CPU 减少 69.49%–99.98%。候选所有完全相同重试均为 0 字节写入。固定增量时，5 倍历史的写入比为账户 0.625、原生 1.0、长会话 1.1897，均小于 2。SQLite 页布局可使较大库的单次写入低于较小库，不将这种差异外推为规模越大越省资源。

首次迁移成本单列：1 倍 ledger/native 分别约 2.51 / 1.60 秒，写入 127.4 / 138.1 MB；5 倍约 12.99 / 8.75 秒，写入 674.3 / 727.9 MB。包括备份、事务导入和验证，不能计作稳态成本。

合成半行 EOF 子进程三次对照：基线 CPU 1.992–1.998 秒、wall 约 2.00 秒超时；候选 CPU 0.0043–0.0051 秒、wall 约 0.073–0.076 秒返回既有协议错误。该 CPU 统计不含轻量 shell 子进程。

[匿名性能摘要](evidence/2026-10-23-v1.4.2/final-performance-summary.json)与[进程对照](evidence/2026-10-23-v1.4.2/final-process-partial-eof.json)记录原始计数。存储 CPU/实际写入取自当前进程 `proc_pid_rusage`，CPU 单位换算已用 `getrusage` 独立交叉检查。以上属于离线组件门禁；整应用加辅助进程的持续能耗、主线程 100 ms 门槛仍待实机验证。
