原生读取固定官方源码版本 `b741e480e203f037ca726bc2a76d99a8e8668e66`，Rust 1.95.0 和锁定依赖。只允许 `identity`、`snapshot` 两个固定命令。官方认证组件处理凭据，输出包含安装盐参与计算的账户标识，不包含令牌、Cookie、邮箱或原始账户 ID。辅助程序及依赖许可随包提供。

最新榜单 metrics schema 3 的在线读取通过，模型记录和辅助历史成功解析。费用显示遵循上游每条记录的聚合标记；旧口径费用历史不混入新曲线。本机今日统计仍来自本机账本。
