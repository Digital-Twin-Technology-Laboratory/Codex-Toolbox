## Spec

初审发现 2 项 P1，复审均关闭：

- S01：跨时区旧历史不能完整重放时，直接跳过线程导致以后追加的 Token 永久漏记。修复为保留原日桶、建立保守基线并用经验证的增量检查点继续采集；提交成功后才更新拒绝重放缓存。
- S02：回退旧版期间新增/修改日桶会丢掉已有日期来源。修复为可选 `dayBucketTimezones` 元数据：保留旧日期来源，重叠桶记录混合来源，已删除桶不恢复；无法可靠归属的任务保持不完整且不参与精确额度/费用计算。

独立复核在隔离副本运行 46 项存储/读取回归，全部通过，包含组合场景：旧版修改及删除日桶 → 升级 → 追加 → 重启再追加 → 清除 → 重开导出为空。组合回归已收入主工作区。审查未操作活动应用、真实账户或在线发布状态。

结论：Standards 0 硬性问题 / 1 低优先级建议；Spec 2 项已关闭 / 0 项未解决。静态和隔离回归结论不替代真实设备验收。
