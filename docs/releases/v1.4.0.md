# Codex Toolbox 1.4.0

发布日期：2026-10-05。Build 58，正式版。

把模型榜单、本机用量和账户剩余额度放进各自的菜单栏项目。这次更新保留原有看板和历史数据，并改进任务每日额度与当前任务名称的显示。

## 多菜单栏与独立样式

固定三个槽位，可分别开关、自由选择并重复显示内容，至少保留一个。新安装默认配置综合榜单、今日 Token、账户剩余额度，仅开启第一项；升级保留已有榜单与外观设置。按住 Command 拖动图标可调整系统位置。

菜单栏设置新增常驻预览。榜单、Token 与额度拥有独立样式；Token 可选完整数字或 K/M/B，额度可选进度条、圆圈、百分比和彩色/单色。点击项目会定位并临时展开对应模块，关闭后保留原有布局。

## 账户额度与每日用量

- “账户额度&重置卡”展示套餐类型、实际支持的窗口、剩余额度、北京时间重置日期和重置卡。折叠时优先显示周剩余额度；过期或缺失信息有明确提示。
- “用量分析”保留本机任务排行与每日趋势。完整当日原生记录显示 `=`，部分差值或校准估算显示 `≈`；无可靠数据时不显示虚假的零消耗。
- 原生任务快照按账户隔离，保留 90 天；账户切换拒收旧请求，跨日缺测、延迟和额度修正不会直接归入今天。
- 任务名称优先使用 Codex 当前侧栏名称，改名后刷新即可同步；归档、旧格式或日志缺失保留兼容回退与历史 Token。

## 成本、模型榜单与稳定性

本机 Credits、API 等值成本和价格更新集中到默认关闭的“本机成本换算”实验中。关闭后隐藏成本并停止相关请求与计算；已有成本菜单栏槽位临时显示 Token，重新开启即可恢复。金额仅为 API 等值估算，不是订阅账单。

最新模型榜单接入 Radar metrics schema 3，按来源标注费用聚合方式和计分样本，并隔离不同统计口径的历史。修复异常版本信息引起的更新检查崩溃，完善空态、重置日期、套餐颜色与缓存提示。

## 安装与数据

支持 macOS 14 及以上，提供 arm64 + x86_64 Universal 2 PKG 和 DMG；采用 Developer ID 签名与 Apple 公证。推荐使用 PKG 覆盖安装。使用 DMG 从旧 Show Codex IQ 升级时，请先退出并删除旧 `Show Codex IQ.app`，再将 Codex Toolbox 拖入 Applications；以包内安装说明为准。

Bundle ID、既有设置及本机历史保留。应用不调用模型、不兑换重置卡；原生任务查询仅向官方服务发送聊天 ID、创建日期和子代理 ID，不发送标题、正文或文件内容。API 登录不查询 ChatGPT 套餐任务额度。详情见 [隐私说明](https://github.com/Digital-Twin-Technology-Laboratory/Codex-Toolbox/blob/main/docs/privacy.md)。

本版本不包含个人网站数据适配服务、后台管理、远程展示配置、套餐历史页或 AI 推荐。
