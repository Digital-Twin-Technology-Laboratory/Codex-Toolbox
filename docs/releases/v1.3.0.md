# Codex Toolbox v1.3.0

v1.3.0 扩展模型选择与 Token 成本分析，同时完成一轮看板交互、可访问性和发布链路加固。

## 模型智商与推荐

- 新增默认关闭的站长推荐，按日常开发、困难任务、后台自动化和龙虾任务展示四类紧凑推荐，并使用独立缓存与过期状态。
- 第四榜单可在本地加权综合与 Codex Radar 成本效率之间切换；成本效率直接使用公开 `combined_cost_index`，越低越好。
- 新增模型可见性管理。默认仅显示 GPT，也可按 OpenAI、xAI、Moonshot、DeepSeek、DSH、智谱等提供商或具体模型家族切换。
- 模型家族简称统一用于菜单栏、榜单、趋势和推荐；旧版逐档位简称会在无歧义时迁移。
- 模型简称改为按提供商和家族管理，编辑时保留内部空格，展开详情继续显示官方全名。
- IQ 趋势使用自适应纵轴范围，并以颜色、线型和点型共同区分系列；相近曲线不再因强制包含零点而被压扁。

## Token、Credits 与 API 等值成本

- Usage Ledger 升级到 schema 7，按事件保存 Token 分项、模型、推理强度、Standard/Fast、费率制度和历史费率版本。
- Credits 按公开 Codex 费率和事件时间计算，不重复计算 cached input 或 reasoning output；API Key 用量不套用 ChatGPT Credits。
- 新增 API 等值成本：OpenAI 模型使用官方 API 价格，其他已支持模型使用 models.dev 快照，支持长上下文、Fast 和缓存写入价格。
- Token 任务、当日总览与趋势可显示成本、分项明细、覆盖率和估算精度；菜单栏成本默认关闭。
- 活动任务期间只读采样账户额度窗口，区分本机任务、其他设备/共享产品消耗和并发干扰；逐任务估算总和不会超过账户权威已用比例。
- 在线费率或 API 价格检查失败时保留内置/缓存版本，并明确说明本地回退，不再显示泛化的“数据服务器暂不可用”。

## 看板、主题与交互

- 四宫格榜单统一顶部对齐和常规行高，展开说明只显示一次；Radar 小数保留足够有效数字。
- 榜单展开动画仅匹配材质，文字内容交叉淡化，减少模型名拉伸、重排和顿挫。
- 站长推荐、榜单和 Token 任务卡统一轻量悬停与按压反馈；静态卡片不再启用交互光晕。
- 新增默认隐藏的实验性入口，可选择彩色玻璃、清透玻璃和扁平中性主题；关闭实验功能会继续使用默认彩色玻璃。
- Reduce Motion、Reduce Transparency 与 Increased Contrast 均有对应回退样式。

## 发布与维护

- 本地测试 PKG 和正式构建都要求 Developer ID 嵌套签名一致，并增加包内应用真实启动烟雾测试。
- API 价格抓取器只在实际价格结构变化时追加历史版本，不再因抓取日期变化每天生成重复版本。
- 正式发布脚本会在创建标签前验证两份远端价格清单返回成功且与发布提交一致，防止安装包发布后出现 404。
- Credits 费率的 OpenAI Help Center 页面当前会阻止 GitHub Runner 自动抓取，因此维护工作流暂时改为人工核对触发；应用仍保留项目托管清单、缓存和内置回退。

本 Release 将提供 Developer ID 签名、Apple 公证并 staple ticket 的 Universal 2 PKG 与 DMG，以及对应 SHA-256 校验文件和 Sparkle appcast。
