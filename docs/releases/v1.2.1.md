# Codex Toolbox v1.2.1

v1.2.1 是一次界面可读性与设置结构更新。

- Token 任务卡中的总量改为独占一行，位数较多时保持单行并自适应缩放。
- 模型榜单优先完整显示模型名称，空间不足时先收紧和缩小，最后才使用省略号。
- “智商显示”和 Token 设置按功能重新分组，减少连续堆叠的控件。
- 通用、Token 与重置卡页面不再重复显示数据访问边界；详细说明集中到“关于 → 数据与隐私详情”。

本 Release 将提供已签名、Apple 公证并 staple ticket 的 Universal 2 PKG 与 DMG，以及对应的 SHA-256 校验文件。
