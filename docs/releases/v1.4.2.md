# Codex Toolbox 1.4.2

Build 65。

修复 1.4.1 中可能出现的卡顿、磁盘频繁读写和能耗偏高问题。界面、刷新周期、账户隔离和额度计算口径保持不变。

- 历史用量、任务额度和图表数据改在后台准备，切换日期、展开明细和滚动时不再重复整轮计算。
- 历史记录改用增量存储，小量更新只写入变化部分；公共数据未变化时不再重写本地缓存。
- 后台刷新只保留最新请求，面板关闭、睡眠唤醒或切换账户时及时取消过期任务。
- 修复辅助进程异常响应时的空转、取消与退出处理，以及异常数值可能引起的崩溃。
- 修复 Codex 退出或清理数据库临时文件后，Token 用量偶尔提示“未找到可读取的 Codex 状态数据库”的问题。
- 账户额度、Token 统计、费用估算及实验功能的默认开关不变。

首次启动会自动迁移现有历史，并在原目录保留迁移前备份；迁移期间可能短暂占用较多磁盘和 CPU。如需回退到 1.4.1，请先参阅[迁移与回退说明](https://github.com/Digital-Twin-Technology-Laboratory/Codex-Toolbox/blob/main/docs/verification/v1.4.2-build64-migration.md)。

从 Show Codex IQ 升级时，请先删除旧的 `Show Codex IQ.app`，再安装 Codex Toolbox。
