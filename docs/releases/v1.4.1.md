# Codex Toolbox 1.4.1

Build 63。

更换稳定的数据接口，支持动态调整数据与适配上游变化。现有协议范围内的数据和来源调整无需通过软件更新适配。

- 榜单、兼容历史、站长推荐、官方费率及 API 价格统一通过稳定接口提供。
- 保留有效缓存和用户设置；接口或上游暂不可用时继续使用有效数据，并显示历史数据状态。
- 支持动态切换评分基准与评分名称；费用或耗时缺失时，不拼接旧值或生成不完整的综合排名。
- 恢复“智商最高／费用最低／耗时最低／综合最佳”标题，模型智商手动刷新提供短暂结果反馈。
- 修复推荐回退状态、公共数据缓存验证器及重复缓存导致的崩溃风险。
- 账户额度、Token 统计及实验功能的默认开关不变。
- 日期栏恢复“Codex 雷达数据日期”，评测基准详情保留在悬停说明；账户额度折叠摘要省略“缓存”字样。

当前提供旧 DeepSWE 的真实历史成绩，日期为 2026-10-04。非 GPT 费用和 Radar 成本效率指数尚未恢复，相关缺失指标显示暂无数据；默认本地加权榜可对完整指标计算。上游尚未提供的新成绩不会凭空出现。

从 Show Codex IQ 升级时，请先删除旧的 `Show Codex IQ.app`，再安装 Codex Toolbox。
