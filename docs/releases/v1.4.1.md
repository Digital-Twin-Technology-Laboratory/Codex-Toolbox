# Codex Toolbox 1.4.1

Build 61，候选版，尚未正式发布。

本次统一迁移公共数据接入：客户端改读 zjwspace.cn 的稳定接口，由网站集中适配上游数据格式，减少因换源重新安装软件的次数。

- 榜单、兼容历史、数据日期和同步状态由自有接口统一提供。
- 保留有效缓存和用户设置；网站或上游暂不可用时，明确展示历史数据状态。
- 支持服务端确认后切换评分基准；评分名称自动变化，费用/耗时缺失时不拼接旧值或生成不完整的综合排名。
- 站长推荐、官方费率与 API 价格统一从个人网站读取，失败保留有效缓存与内置费率。
- 网站后台新增 Codex Toolbox 看板，可查看状态、同步、预览并启用来源、暂停/恢复和回退。
- 客户端界面保持 Build 60，账户额度、Token 统计及实验功能的默认开关不变。
- 日期栏恢复“Codex 雷达数据日期”，评测基准详情保留在悬停说明；账户额度折叠摘要省略“缓存”字样。

当前上线数据是旧 DeepSWE 的真实历史成绩，日期为 2026-10-04。非 GPT 费用和 Radar 成本效率指数尚未恢复，相关缺失指标显示暂无数据；默认本地加权榜可对完整指标计算。上游尚未提供的新成绩不会凭空出现。

源码验证、网站部署、安装包校验及手动验收范围见 [验证记录](../verification/v1.4.1.md)。正式标签、GitHub Release 与 appcast 仍待发布授权。
