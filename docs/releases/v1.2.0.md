# Codex Toolbox v1.2.0

v1.2.0 修正 Codex 雷达榜单数据口径，新增每日 Token 下钻，并改进本机任务额度估算。

## 模型榜单

- 改用 Codex 雷达公开 21 档聚合快照，补齐 GPT-5.6 Sol ultra/max、Terra ultra 和 DeepSeek V4 Flash。
- 费用与耗时与网站统一为每题平均值，趋势使用同一聚合快照的历史点。
- 新快照使用独立缓存，不会混入旧版累计费用或耗时；“综合最佳”明确标识为本地加权百分位。

## 每日任务明细

- 点击“每日用量趋势”柱形可查看对应日期的根任务明细。
- 历史日期保留“返回今日”，关闭弹窗后下次打开默认恢复今日。
- 修复 macOS 26 Liquid Glass 下“返回今日”内容不显示及历史任务卡顶部间距异常。
- 任务卡继续支持整卡点击，在 Top 3 与设置的展开数量之间切换。

## 任务额度估算

- 任务百分比与同一行显示的本地日期、根任务严格对应，不再把整周任务估算放在今日 Token 后。
- 根据 OpenAI [Codex rate card](https://help.openai.com/en/articles/20001106-codex-rate-card) 中模型的输入、缓存输入和输出信用费率生成相对权重，再使用本机额度快照稳健校准。
- 上述 token-based 权重不适用于少量仍使用 legacy rate card 的企业账户。
- 异常并发或延迟台阶不再成为单个任务长期复用的换算率。
- 升级时不再保留旧原始 Token 口径的历史校准点，避免与新模型权重混用。
- 任务值仍是本机估算，不代表 OpenAI 官方逐任务账单或精确额度拆分。
- 任务卡保持原生键盘操作和 140ms 按压反馈；趋势悬停只在目标日期变化时刷新。
- 滚动条按实时内容与可视区高度显示，并通过防抖、滞回与可视区收缩判断过滤展开/折叠动画中的瞬时假溢出。
- 安装器增加兜底：旧应用未响应时自动结束残留进程，升级不会再因应用无法退出而失败。
