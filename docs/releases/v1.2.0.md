# Codex Toolbox v1.2.0

v1.2.0 修正 Codex 雷达榜单数据口径，重做模型趋势交互，新增每日 Token 下钻，并改进本机任务额度估算、菜单栏性能与安装体验。

## 模型榜单

- 改用 Codex 雷达公开 21 档聚合快照，补齐 GPT-5.6 Sol ultra/max、Terra ultra 和 DeepSeek V4 Flash。
- 费用与耗时与网站统一为每题平均值，趋势使用同一聚合快照的历史点。
- 新快照使用独立缓存，不会混入旧版累计费用或耗时；“综合最佳”明确标识为本地加权百分位。
- 变化趋势在输入变化时于后台一次性准备图表和模型选择数据，展开、悬浮与切换不再反复解析完整历史。
- 变化趋势改为五个固定颜色槽：每种颜色可通过原有家族分类菜单指定模型，可增删至 1–5 条并恢复默认 Top 3。
- 曲线槽使用紧凑三列排版，默认 3 条同行展示；筛选菜单会展示家族中全部档位，并明确标识当前颜色及被其他颜色占用的档位。
- 曲线槽使用模型目录提供的短标签，优先显示家族和档位差异，例如 `Sol max`、`Sol ultra`、`Sol med`；悬停仍可查看完整名称。
- 趋势入口出现时会预热当前指标，展开/折叠复用看板原生临界阻尼动效；设置可选择每次打开看板时默认展开，当前会话中仍可手动折叠。
- 图表日期、横轴刻度和每日详情在后台准备时一次生成，悬停仅作二分查找，减少主线程指针事件开销。
- 悬浮详情安置在曲线绘图区上方的固定安全区；1–3 条曲线逐模型单行显示，4–5 条才切换双列，横向自动避让左右边界且不遮挡数据线。
- 连续悬浮状态限定在绘图子视图内，趋势复合卡使用静态 Liquid Glass，避免下方文字和曲线控件随鼠标日期切换而反复变亮、变暗。
- 设置可选择在展开榜单中显示其他指标，默认关闭；展开后只显示一次指标表头，各模型行仅保留对齐数值，综合榜单可同时查看智商、费用和耗时原始值。
- 使用曲线筛选菜单后，点击弹窗外部仍会正常收起整个菜单栏界面。
- 展开榜单的表头与每行数值使用同一列宽和尾端对齐；表头模式仅收紧自身额外间距，不再让常规 Top 5 展开状态触发滚动条。

## 每日任务明细

- 点击“每日用量趋势”柱形可查看对应日期的根任务明细。
- 历史日期保留“返回今日”，关闭弹窗后下次打开默认恢复今日。
- 修复 macOS 26 Liquid Glass 下“返回今日”内容不显示及历史任务卡顶部间距异常。
- 任务卡继续支持整卡点击，在 Top 3 与设置的展开数量之间切换。

## 任务额度估算

- 任务百分比与同一行显示的本地日期、根任务严格对应，不再把整周任务估算放在今日 Token 后。
- 根据 OpenAI 于 2026-08-04 更新、并在正式发布前再次核对的 [Codex rate card](https://help.openai.com/en/articles/20001106-codex-rate-card)，按模型当前标准模式的输入、缓存输入和输出信用费率生成相对权重，再使用本机额度快照稳健校准。
- 上述 token-based 权重不适用于少量仍使用 legacy rate card 的企业账户。
- Rollout 当前不会记录逐事件的 Fast 模式状态，因此不会凭配置猜测倍率；若一个连续活动区段稳定使用 Fast 模式，本机额度百分点校准会吸收其实际倍率，混用 Standard/Fast 时仍只能作为近似值。
- 异常并发或延迟台阶不再成为单个任务长期复用的换算率。
- 升级时不再保留旧原始 Token 口径或旧费率表的历史校准点，避免与新模型权重混用。
- 任务值仍是本机估算，不代表 OpenAI 官方逐任务账单或精确额度拆分。

## 性能、交互与安装体验

- 任务卡保持原生键盘操作和 140ms 按压反馈；趋势悬停只在目标日期变化时刷新。
- 滚动条按实时内容与可视区高度显示，并通过防抖、滞回与可视区收缩判断过滤展开/折叠动画中的瞬时假溢出。
- 安装器增加兜底：旧应用未响应时自动结束残留进程，升级不会再因应用无法退出而失败。
- PKG 安装界面显示完整的 Codex Toolbox 产品名；若安装前应用正在运行，替换完成后会自动启动新版本。

## 相关功能默认设置

- “展开榜单显示其他指标”：关闭。
- “显示模型趋势入口”：关闭；因此“固定展开”和趋势范围控件在开启入口前不可用。
- “固定展开”：关闭。开启后每次打开菜单栏弹窗默认展开趋势，但当前弹窗内仍可手动折叠。
- 模型趋势范围：最近 7 天。
- 趋势曲线：没有预存自定义选择，按当前指标自动显示 Top 3；用户可调整为 1–5 条，恢复默认会重新回到动态 Top 3。
- 每日 Token 趋势：最近 7 天；任务卡默认显示 Top 3，展开后显示 Top 5；关闭菜单栏弹窗后日期恢复今日。
- 综合榜单权重：智商 50%、费用 25%、耗时 25%。
