# Codex Toolbox v1.3.1

v1.3.1 是针对网络切换、Mac 休眠/唤醒以及 Codex 账户用量服务瞬时故障的小型稳定性更新。

## 模型 Radar

- Radar 请求会等待系统连接恢复，并仅对断网、连接中断、DNS、主机不可达和超时执行有上限的重试。
- 有上次数据时，瞬时网络失败继续显示榜单并标注“缓存”，不再挂着底层英文断网错误。
- HTTP、数据结构和解析错误仍会正常提示，不会被当作网络瞬断隐藏。

## 检查更新

- 手动检查更新遇到瞬时断网时会有限重试，过程中显示中文恢复状态。
- 后台检查瞬时失败不再留下橙色错误；签名、解压和安装等非网络错误仍然可见。
- Sparkle 2.9.2 仍完整负责 appcast、Ed25519 验签、下载、解压和安装，本次没有替换更新安全链。

## 重置卡

- Codex app-server 访问账户用量服务偶发 JSON-RPC `-32603` 或超时时，会重新启动短生命周期 app-server 并有限重试只读查询。
- app-server 初始化和账户查询各自获得完整超时窗口，不再共用一个已被初始化消耗的截止时间。
- 重试仍失败时，若已有上次成功数据，将继续显示并标注“缓存”，不再持续显示橙色 app-server 错误。
- 服务成功响应但临时省略逐卡数组时，只要可用总数未变化，就保留并标注上次已知明细，不再用空数组覆盖磁盘缓存；总数变化或返回新明细时仍以新结果为准。
- 仍只调用 `account/rateLimits/read`，不调用 consume，不输出或保存 access token、refresh token、cookie 或完整唯一 ID。

## 系统生命周期

- Mac 进入睡眠前停止 Toolbox 自有刷新调度，唤醒后留出短暂的 Wi-Fi、路由和本地代理恢复窗口，再刷新到期数据。

本 Release 提供 Developer ID 签名、Apple 公证并 staple ticket 的 Universal 2 PKG 与 DMG，以及对应 SHA-256 校验文件和 Sparkle appcast。
